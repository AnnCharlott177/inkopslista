# Inköpslistan 🛒

En enkel och glad inköpslista som körs direkt i webbläsaren.

## Vad appen gör

- Lägg till varor i listan.
- Bocka av varor när de ligger i korgen. Avbockade varor flyttas längst ner.
- Ta bort enskilda varor med ×-knappen.
- Rensa alla avbockade varor med en knapp.
- Listan sparas i webbläsaren (localStorage) och finns kvar när du laddar om sidan.

Appen fungerar lika bra på mobil som på dator.

## Så använder du den

Öppna `index.html` i en webbläsare. Det behövs ingen server, inget byggsteg och inga paket.

För att publicera den på GitHub Pages lägger du filerna i ett repo och aktiverar Pages för den gren och mapp där `index.html` ligger.

## Filer

- `index.html` – startsidan
- `style.css` – utseendet
- `app.js` – logiken och sparandet
- `favicon.svg` – ikonen
